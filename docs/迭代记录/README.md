## 记录规则

- 新增记录使用 `YYYY-MM-DD-主题.md` 命名。
- 每条记录建议包含：已完成事项、关键决策、后续方向、暂不推进内容、关联 TODO/OpenSpec/Research。
- 工作流规范仍放在 `docs/workflows/`；这里放实际迭代流水和阶段复盘。
- 不确定、需要共同确认的问题放到 `docs/xq-todo.md`。
