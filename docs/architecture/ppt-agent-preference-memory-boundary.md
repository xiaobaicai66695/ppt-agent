# PPT Agent 风格输入边界

更新时间：2026-08-27

本文档记录当前风格输入策略。固定风格、称谓、组织背景、配色、表达口吻和品牌要求都属于当前任务输入，由用户在提示词或全局提示词中显式提供。

## 当前决策

- 创建入口只负责请求分流：新建 PPT、修改已有任务、主题澄清或闲聊。
- Planner 只使用当前任务可见输入生成 DeckSpec。
- Task Reviewer 只检查需求匹配、叙事结构、组件 schema、信息密度、事实来源和布局容量。
- 生成结果、QA 分数、任务输出和渲染产物都不回写为长期风格规则。

## 使用方式

用户需要固定表达方式时，应直接写在当前请求里，例如：

- “用投资委员会汇报口吻，结论先行。”
- “称呼公司为 XX 集团，避免互联网黑话。”
- “配色偏克制，适合政府汇报。”
- “每页保留数据来源，不写夸张营销词。”

这些要求只在当前任务内生效。需要长期复用时，由用户维护在全局提示词中。

## 后续恢复条件

如果未来重新做自动记忆能力，必须先完成独立设计和用户可见控制：

- 明确哪些内容会被记住、为什么被记住，以及如何撤销。
- 只接受用户显式授权的输入来源。
- 每条记录有来源、场景、时间和置信度。
- 进入 Planner 前以结构化字段传递，不能拼接成无来源的自然语言长段。
