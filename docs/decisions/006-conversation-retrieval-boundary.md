# 006 对话、检索与用户可见轨迹决策

## 当前决策

一个用户任务是会话与 PPT 工作流的统一载体。入口先做受控意图路由，再在同一任务 ID 内执行闲聊、澄清、规划、生成或定点修复；任务切换和断线恢复不得重新分配会话上下文。

聊天中的网页和图片资料是受边界保护的补充能力：只提取受限的公开内容、拒绝内网/本地地址与危险重定向、保留来源，不把原始网页或凭据直接灌入 Agent 上下文。

## 执行准则

- 仅向用户显示模型的显式回答、请求阶段、工具名称和经过整理的结果摘要；不展示私有推理、原始工具参数或敏感运行数据。
- SSE 只有明确的任务终态事件才能关闭；说明文本结束不等于 PPT 渲染和交付完成。
- 图片候选、来源和归属作为独立的可点击内容呈现；流式 Markdown 未闭合时先按文本保留，不能制造损坏链接或图片。
- 检索失败、没有素材或能力不可用时如实降级，不编造链接、图片或已执行的工具结果。
- 会话和生成状态均以任务持久化状态与事件游标恢复，前端不得用局部内存推断终态。

## 取舍

受控轨迹会少于完整模型过程，但能同时避免思维链泄露、重复会话、流状态错乱和不可信外部内容进入任务上下文。
