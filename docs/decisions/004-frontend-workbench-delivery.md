# 004 前端工作台与交付体验决策

## 当前决策

前端定位为 PPT 生产工作台，而不是营销式展示页。核心体验围绕统一会话、任务列表、模板选择、进度可观测、渐进式预览、结果下载和运行详情展开。

## 执行准则

- 任务页和创作入口共享同一会话语境，避免返回任务页后 AI 对话重复或丢失上下文。
- 预览状态必须区分生成中、缺缩略图、转换失败、文件不存在，不把所有异常都显示为仍在生成。
- 模板、背景和缩略图优先使用后端真实接口资源，不用纯装饰渐变或假图替代。
- Timeline 默认轻量展示，完整 metadata 放在事件详情中，并支持按事件类型筛选。
- 同一任务 ID 内按到达顺序展示用户消息、安全的请求阶段、工具调用/结果和助手显式回答；不展示模型私有推理。
- `answer_end` 只表示说明文本结束，SSE 仅在明确的交付或会话终态事件后关闭。
- UI 采用信息密度适中的工作台风格，关键操作路径明确，避免大而空的单页和不可扫描的卡片堆叠。
- 大页面继续增长时优先拆组件、composable 或工具函数。

## 取舍

工作台式 UI 不追求第一屏视觉噱头，但能更好服务反复生成、查看、续聊、定位失败和下载交付这些高频任务。
