# 配色方案参考

## 硬性禁止

禁止使用任何刺眼的"原色"，必须使用低饱和度灰感色彩。

| 类别 | 禁止颜色示例 |
|------|-------------|
| 纯色原相 | `#FF0000` `#00FF00` `#0000FF` `#FFFF00` |
| 霓虹色 | `#FF00FF` `#00FFFF` `#FF6600` |
| 紫色渐变 | 紫色到蓝色/粉色的渐变（典型AI感配色） |
