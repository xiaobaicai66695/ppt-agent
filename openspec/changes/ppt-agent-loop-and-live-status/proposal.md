## Why

任务页在切换后会同时恢复持久化会话并从头回放 SSE，导致同一轮 AI 内容重复。PPT 生成过程中，主 Agent 还依赖模型反复整文件修改和校验 `tasks.json`，既拖慢闭环，也容易产生无效重试和 JSON 写入错误；用户又缺少一个持续更新的运行状态来判断系统是否仍在工作。

## What Changes

- 为任务会话恢复增加稳定的 SSE 事件游标，切换页面后只消费未见事件，并保留任务级流式回答状态。
- 将会话历史恢复与实时流合并为幂等流程，避免历史回答和重放事件重复生成 AI 消息。
- 增加受控的任务清单更新能力，以结构化、原子方式更新页面内容和状态，禁止主 Agent 用通用文件工具反复覆盖 `tasks.json`。
- 由文件落地与后端协调器自动收敛页面状态，减少每页生成后的模型读写往返。
- 在统一会话框中增加实时状态行，明确显示思考、读取、搜索、生成、重试、连接恢复和完成等状态。
- 收敛用户可见的 Agent 输出：聊天区保留方案、关键决策和结果，工具细节进入状态行与执行轨迹。

## Capabilities

### New Capabilities
- `agent-live-status`: 为生成任务提供幂等会话恢复、事件游标和面向用户的实时运行状态。
- `manifest-mutation`: 为 `tasks.json` 提供结构化、原子、可校验的清单更新与自动状态收敛。

## Impact

- 前端：`DashboardPage.vue`、`ConversationComposer.vue`、会话类型与工作台工具函数。
- 后端：任务 SSE/会话接口、任务状态缓存、DeepAgent 工具配置与主 prompt、`tasks.json` 读写逻辑。
- API：会话响应新增最新事件游标；SSE 事件和现有 URL 保持兼容。
- 验证：新增前端幂等恢复测试、后端事件游标与清单原子更新测试，并执行聚焦构建。
